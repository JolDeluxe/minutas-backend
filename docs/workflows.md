# Workflows Operativos

# Flujo General

```text
Junta
↓
Captura rápida
↓
Entradas organizacionales
↓
Organización post-junta
↓
Seguimiento
↓
Formalización opcional
↓
Trabajo operativo
↓
Cierre
FASE 1 — Captura

Objetivo:
registrar información rápidamente.

La captura debe tomar segundos.

La asistente registra:

descripción
área
línea
clasificación
imágenes
fecha mencionada

NO se fuerzan:

responsables
deadlines
ejecución
workflows
FASE 2 — Organización

Las jefaturas revisan entradas capturadas.

Pueden:

clasificar mejor
asignar seguimiento
formalizar
descartar
cerrar
derivar trabajo
Flujo Conceptual

Aplica a TODAS las entradas.

CAPTURADO
↓
EN_REVISION
↓
CERRADO

Alternativa:

CAPTURADO
↓
DESCARTADO
Flujo Operativo

SOLO para entradas formalizadas.

PENDIENTE
↓
EN_PROGRESO
↓
COMPLETADO
Formalización

Formalizar significa:

convertir una entrada en trabajo operativo real

Al formalizar:

se asignan responsables
se define deadline
se activan métricas
se activa ejecución
Entradas Derivadas

Una entrada puede generar otras entradas.

Ejemplo:

[ ANALISIS ]
Analizar defectos modelo
│
├── [ CORRECCION ]
│   Ajustar color
│
└── [ MUESTRA ]
    Crear nueva prueba

Las derivadas:

tienen lifecycle independiente
NO cierran automáticamente la entrada original
Seguimiento Ligero

Algunas entradas:

nunca se formalizan
nunca generan tareas
solo permanecen visibles para seguimiento

Esto es válido y esperado.
